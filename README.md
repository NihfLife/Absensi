# Absensi
Ini adalah aplikasi untuk absensi menggunakan sensor NFC pada HP.

Pengembangannya menggunakan MIT App Inventor. Bawaan MIT tidak bisa mendeteksi chip NFC pada KTP karena itu saya menggunakan extension pihak ketiga.

Saya mengunggahnya ke https://play.google.com/store/apps/details?id=appinventor.ai_muhammad_syahrul51.Absensi_NFC agar bisa langsung dicoba. 
Versi 1.2 menambahkan fitur cetak
